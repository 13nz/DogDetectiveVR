# Dog Detective VR

A virtual reality detective game where players take on the role of a dog and use canine abilities to solve a simple mystery.

## About the project

Dog Detective VR is a Unity-based virtual reality game designed to explore how dog-specific abilities can create an engaging and distinctive VR experience.

The player explores a cabin and its surrounding garden, follows scent clues, investigates the environment, and searches for a missing set of keys. The game combines exploration, environmental interaction, and a short narrative to create a complete, accessible gameplay experience.

The project focuses on making the player feel like a dog rather than simply placing a human player in a dog-themed environment.

## Gameplay

The player begins inside a cabin after the owner asks for help finding their missing keys.

To solve the mystery, the player must:

1. Explore the cabin and garden.
2. Use the sniffing mechanic to investigate scent clues.
3. Follow the clues to discover where the keys were left.
4. Use the standing mechanic to inspect higher surfaces.
5. Pick up and carry the keys.
6. Return the keys to the owner to complete the game.

The owner is represented through voice lines rather than a 3D human character. This allows the narrative to remain clear while keeping the project focused on the player's experience as a dog.

## Key features

* Virtual reality exploration using an XR Origin.
* Dog-specific sniffing interaction.
* Standing mechanic for reaching higher surfaces.
* Object interaction and carrying.
* Scent-based clues and environmental investigation.
* Objective progression and subtitles.
* Voice-based narrative.
* Cabin and garden environment.
* A complete beginning-to-end gameplay loop.

## Getting started

### Requirements

* Unity Hub
* The Unity Editor version used to create this project
* A compatible VR headset and PC VR setup
* XR Interaction Toolkit
* Unity Input System

### Opening the project

1. Clone or download the repository.
2. Open Unity Hub.
3. Select **Add project from disk**.
4. Choose the project folder.
5. Open the project using the required Unity Editor version.
6. Open the main gameplay scene.
7. Press Play to test the project.

### Testing without a VR headset

The project can also be tested using Unity's XR Device Simulator, which allows keyboard and mouse input to simulate VR devices.

This is useful for testing the environment, movement, and interactions during development. Testing in the actual VR headset is still recommended before the final submission.

## Development

The project was developed incrementally, beginning with a prototype showcasing core VR interaction mechanics and then expanding into a complete environment and gameplay experience.

The main development priorities were:

* Establishing reliable VR movement and interaction.
* Creating a usable sniffing mechanic.
* Designing a clear clue-based gameplay loop.
* Building a cabin and garden environment.
* Adding narrative feedback through voice lines and subtitles.
* Testing and improving the overall player experience.

## Current status

The project is currently in development.

The main gameplay mechanics and environment are being combined into a complete playable experience. Further development focuses on improving the clue progression, environmental polish, audio, and overall usability.
